# Console Bank Account Application

Учебный проект на Java Core, демонстрирующий работу с ООП, коллекциями и файловой системой.

## Реализованный функционал:
- Пополнение и снятие средств с проверкой баланса
- Ведение истории операций с использованием `LocalDateTime`
- Подсчет общей суммы пополнений и снятий через циклы
- Защита от некорректного ввода данных (`try-catch`)
- Экспорт истории операций в текстовый файл (`BufferedWriter`)

## Технологии:
- Java Core
- Collections (ArrayList)
- Date/Time API (LocalDateTime, DateTimeFormatter)
- File I/O (BufferedWriter, FileWriter)
- Git & GitHub

## Как запустить:
1. Клонируйте репозиторий
2. Откройте проект в IntelliJ IDEA
3. Запустите метод `main` в классе `BankApp`
4. Следуйте инструкциям в консольном меню
